## English

This example demonstrates how to use the `flutter_opencv_ffi` plugin in a Flutter application.

### Features Demonstrated

- Document/label 8-point detection
- Perspective crop and enhancement
- Edge detection
- Image processing with OpenCV

### Running the Example

1. Navigate to the example directory:

```bash
cd example
```

2. Install dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```

For HarmonyOS (OHOS) devices:

```bash
flutter run -d ohos
```

### Requirements

- Flutter SDK 3.0 or higher
- For HarmonyOS: DevEco Studio and HarmonyOS SDK
- For Android: Android Studio and Android SDK
- For iOS: Xcode and iOS SDK
